### 1.1 `beer_data_set.csv` 的结构事实

- **5,558 行 × 21 列**，**112 个风格**。
- 抽样结构：**103 个风格恰好 50 款、8 个风格 49 款、1 个风格 16 款**。
  → 这是**按风格等量抽取的平衡样本，不是市场自然分布**。
- 11 个感官字段（Astringency / Body / Alcohol / Bitter / Sweet / Sour / Salty /
  Fruits / Hoppy / Spices / Malty）取值 0–323（Body 最大 197、Sweet 263、Sour 323），
  是**评论词频计数**，**不是 0–6 品评分，也不是 0–100 分制**。
- `Ave Rating` 为 1.27–4.83 的评论均分；`ABV` 0–57.5；`Min/Max IBU` 0–100。
- **没有任何化学测量字段。**
- 数据质量：`key` 唯一；`Name` 有 240 个重名、2 个缺失；其余字段无缺失。

### 1.2 `Beer Descriptors Simplified.xlsx` 的结构事实

- 3 张表：`Mouthfeel`（97 行）、`Taste`（128 行）、`Flavor And Aroma`（209 行）。
- 内容是"描述词 → 11 个感官大类"的成员关系，`Impact` 列全部为 1（二值成员，无权重）。
- 与赛题数据的接口：`7.csv` 的 **186 个描述符中有 80 个能直接命中词典**，
  可据此把 62 个 aroma + 62 个 palate + 62 个 taste 细项聚成 11 个大类。

- **不在赛题附件 1–8 之内**（`data/raw/附件/` 只有 1.csv、2.csv、3.xlsx、4.csv、
  5.csv、6.csv、7.csv、8.xlsx + 数据说明）。
- `archive.zip` 内部成员时间戳为 **2021-09-14**，由队员于 **2026-10-23 22:09** 提供。
- **身份已核实（2026-10-23）**：内容与官方题面推荐的 Kaggle 数据集
  [`stephenpolozoff/top-beer-information`](https://www.kaggle.com/datasets/stephenpolozoff/top-beer-information)
  完全对得上：
  - Kaggle 标题 *Beer Information - Tasting Profiles*，副标题 *Top-Rated Beer Information
    for Tasting Profiles*；描述为"每个风格最多 50 款、共 5,558 款，来自 BeerAdvocate"；
  - 前 10 列为啤酒信息，后 11 列为基于最多 25 条评论词频的 tasting profile；
  - 许可证 **CC BY 4.0**；最后更新 **2021-09-14**（与 zip 成员时间戳一致）；
  - Kaggle `totalBytes = 1,845,485`，正好等于我们两个文件的字节和
    `1,817,734 + 27,751 = 1,845,485`。
- 结论：**它是官方题面明确推荐的公开数据集，不是赛题附件本身。**
  论文中可写"官方题面推荐的公开数据集（Kaggle, CC BY 4.0）"，
  但不得写成"赛题官方提供的补充数据"。
