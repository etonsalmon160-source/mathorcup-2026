## 一、参赛与报名

- 参赛对象：境内外高校在读研究生、本科生、专科生。
- **每队 1–3 人**，最多 1 名指导教师（须为高校全职教师）。
- 允许跨年级、跨专业、跨校组队。
- 组别按队内**最高在读学历**确定：研究生组 / 本科组 / 专科组。
- 报名截止 **2026-10-23 12:00**，截止后不能改报名信息。
- 参赛费 **200 元/队**，报名网站提交或集体缴费。

- 复赛**不换题目背景，但更换问题和数据**。

## 三、题目

- 共 **2 道赛题，任选 1 道**。
- 来源：企业/行业真实场景大数据问题，经过适当简化加工，**不要求预先掌握深入行业知识**。
- 赛题在开赛时于官网与报名网站同时公布，不邮寄书面题目。
- 前 3 届练习题参考：观影数据集分析、新冠肺炎 CT 图像识别。

## 四、提交

- **每天最多提交 1 次**（硬约束，务必登记台账）。
- 三件套：**电子版论文 + 结果数据集 + 计算程序源代码**。
- 支撑材料（程序、数据、结果）压缩打包上传，选择性添加；题目没明确要求的不是必交。
- **源程序即使已放入论文正文附录，仍须单独以支撑材料提交一份**。
- 语言：Python / Matlab / C++ / Java 等均可，需附**详细操作说明文档**。
- 提交规范另见《MathorCup 数学应用挑战赛—大数据竞赛提交规范》（官网）。

## 五、评分标准（四轴）

1. **论文撰写质量** — 摘要需简明概述核心思想与效果；正文详述分析与求解过程；
   模型算法需明确列出并清晰解释；数据处理/求解过程合理、程序正确、结果有分析有结论；
   逻辑清晰、文字简练、参考文献引用恰当。
2. **代码完整性、正确性和效率** — 与论文方案匹配；完整无误、运行稳定；速度与精度高。
3. **问题解答质量** — 在**测试数据集**上验证，准确率、召回率等与实际背景密切相关的指标表现良好。
4. **创新性** — 分析思路新颖、模型构建准确、算法设计新颖、论证有说服力，
   **显现较强的跨学科交叉应用能力**。

> 注意：这不是纯排行榜赛。**论文与创新性占很大权重**，光有高分模型不够。

## 六、奖项

- 分组别、分赛题评选：一等奖 **5%**、二等奖 **15%**、三等奖 **30%**（发证书）。
- 一等奖队伍中答辩决出（不分组别、不分赛题）：
  - 金奖 1 支，奖金 10000 元（税前）
  - 银奖 2 支，每队 5000 元（税前）
  - 铜奖 5 支，每队 2000 元（税前）
- 一等奖队伍优先推荐至企业实习。
- 另评优秀指导教师、优秀组织单位。
