## 一、参赛与报名

- 参赛对象：境内外高校在读研究生、本科生、专科生。
- **每队 1–3 人**，最多 1 名指导教师（须为高校全职教师）。
- 允许跨年级、跨专业、跨校组队。
- 组别按队内**最高在读学历**确定：研究生组 / 本科组 / 专科组。
- 报名截止 **2026-10-23 12:00**，截止后不能改报名信息。
- 参赛费 **200 元/队**，报名网站提交或集体缴费。

## 四、提交

### 4.1 官方原文说了什么（2026 报名通知）

> 出处：`docs/报名通知_2026_大数据竞赛.pdf`，文号 **MathorCup 大数据竞赛[2026-01]号**。

- **每天最多提交 1 次** —— 原文：「每个队伍每天最多提交 1 次。」
- **在竞赛平台上提交** —— 原文：「参赛队伍需在规定的时间内在竞赛平台上提交答卷。」
- 三件套：**电子版论文 + 结果数据集 + 计算程序源代码**。
- 支撑材料（程序、数据、结果）压缩打包上传，**选择性添加**；题目没明确要求的不是必交。
- **源程序即使已放入论文正文附录，仍须单独以支撑材料提交一份**。
- 语言：Python / Matlab / C++ / Java 等均可，需附**详细操作说明文档**。

> 通知里**没有给出提交入口的具体网址**，只说「报名官网的对应电子档提交处」，
> 并指向另一份《MathorCup 数学应用挑战赛—大数据竞赛提交规范》。

### 4.2 提交平台：赛氪 web 上传（**必须人工操作，没有 API**）

> ✅ 2026 版《论文格式及提交规范》已于 **2026-10-23** 发布

2. 打开 **报名管理** → 在「**电子档**」处点「点击提交」
3. 上传论文，并**选择赛道 A 或 B**
4. 点「**提交电子档**」；如修改，点「**更新电子档**」
5. 状态显示「**电子档已提交**」才算成功

> 🔴 **赛道必须与论文内容一致**，不一致「取消评奖资格」。
> 我们已确定选 **A 题**（见 `docs/决策记录.md`），提交时务必选 A。

### 4.3 命名规范（2026 现行，硬要求）

| 材料 | 命名 | 格式 |
|---|---|---|
| 论文 | `#*******.pdf`，例 `A2600001.pdf` | PDF |
| 承诺书 | `#*******承诺书`，例 `A2600001承诺书` | PDF 或图片，每位队员签名 |
| 支撑材料 | `#*******附件.rar` / `.zip`，例 `A2600001附件.rar` | rar / zip |
| AI工具使用详情说明 | `AI工具使用详情说明`（AI 规定原文命名） | PDF，放支撑材料内 |

支撑材料用 `make pack PROBLEM=A TEAM_ID=<参赛编号>` 一键生成，装的是
**源码 + 结果数据集 + 运行说明**，不装 `data/raw/`（组委会提供）和 `models/`（可重训）。

> 论文正文附录里**仍要放全部源程序**（规范原文：「附录中列出所用软件名称、命令和全部源程序」），
> 但这**不替代**附件：源程序必须再单独以支撑材料提交一份。
> 源程序文件要**保存到正式获奖名单公布之后**。

### 4.4 论文格式（不符合即取消评奖资格）

| 项 | 要求 |
|---|---|
| 结构 | 首页：题目 + 摘要 + 关键词；第 2 页：目录；正文从目录之后开始 |
| 页码 | 页脚居中，阿拉伯数字，从 1 连续编号 |
| 页眉 | **不得有页眉** |
| 身份信息 | **不得出现答题人及学校等信息** |
| 语言 | 中文 |
| 篇幅 | **正文 ≤ 30 页**；附录页数不限 |
| 引用 | 正文用方括号标号 `[1][3]`；参考文献按正文出现顺序排列；书籍需注页码 |
| 附录 | 列出软件名称、命令和**全部源程序** |

规范原文：「不符合格式规范的论文将被视为违反竞赛规则，无条件取消评奖资格。」

### 4.5 每天提交几次（已核实）

| 文件 | 原文 |
|---|---|
| 《章程》**第四条**（2026 年 8 月修订） | 「参赛队伍需在规定的时间内在竞赛平台上提交答卷……**每个队伍每天最多提交 1 次。**」 |
| 《论文格式及提交规范》（2026-10） | 「电子档提交（**竞赛期间可多次删除后重新上传最新文档**）」 |

**怎么读这两句**：章程是硬上限——**每天 1 次**；提交规范说的是同一天内可以删掉重传、
改到满意为止，**不是额外的提交次数**。

**做法**：每天只正式提交一次；提交前先在 `submissions/REGISTRY.md` 登记。
开赛后在官方群再问一句「当天删改重传算不算第二次」，以官方答复为准。

## 五、评分标准（四轴）

1. **论文撰写质量** — 摘要需简明概述核心思想与效果；正文详述分析与求解过程；
   模型算法需明确列出并清晰解释；数据处理/求解过程合理、程序正确、结果有分析有结论；
   逻辑清晰、文字简练、参考文献引用恰当。
2. **代码完整性、正确性和效率** — 与论文方案匹配；完整无误、运行稳定；速度与精度高。
3. **问题解答质量** — 在**测试数据集**上验证，准确率、召回率等与实际背景密切相关的指标表现良好。
4. **创新性** — 分析思路新颖、模型构建准确、算法设计新颖、论证有说服力，
   **显现较强的跨学科交叉应用能力**。

> 注意：这不是纯排行榜赛。**论文与创新性占很大权重**，光有高分模型不够。
