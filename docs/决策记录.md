## 怎么写

每次做一个实质决策，加一行。**理由必须是业务/数据理由，不能是"AI 建议的"。**

```markdown
### YYYY-MM-DD HH:MM · 〔决策一句话〕
- **背景**：当前面对什么问题
- **候选方案**：A / B / C（列出来）
- **我们选了**：X
- **理由**：〔业务或数据上的理由〕
- **谁拍的板**：A / B / C
- **AI 起了什么作用**：〔如实写，例："提供了候选方案的性能对比"/"未参与"〕
```

### 2026-10-23 · 问题三"缺陷不恶化"的操作定义
- **背景**：题面写"保持缺陷化合物不恶化……以超阈值项为准"，但没给"不恶化"的数学定义；
  DMS/双乙酰/4VG 有官方阈值，trans-2-nonenal 无阈值，Stale hops 不是化合物。
- **候选方案**：
  A. 严格口径：迁移后所有缺陷物都低于阈值；
  B. 松口径：`OAV_after ≤ max(OAV_before, 1)`，即不新增超标、不加重已有超标；
  C. 只约束变化量 ≤0，不管是否超阈值。
- **我们选了**：**B 为主口径，A 作为对照同时报告**

  C 会允许"本来超标、继续超标"；A 在真实数据里可能根本不存在（实测 0/28 个真实 Tripel 满足）。
- **谁拍的板**：参赛队员（口径由队员确认；AI 提供可行性与代价证据）
- **AI 起了什么作用**：实现 `scripts/q3_probe.py`、跑出两种口径的可行性与代价对比。
- **结果**：松口径 11/11 可行、新增超标 0，风格位移保留 77%、QP 修正代价 40%；
  严口径模型内可行但真实 Tripel 0/28，确认为模型外推，论文必须标注。

### 2026-10-24 · 质控发现接入建模：哨兵值、检出率、低检出样本（待三人确认）
- **背景**：数据体检发现 73 个低于检出限的缺失、7,514 个共享哨兵值
  `log10=-1.817819`、141 列最小值重复 ≥5 次；直接中位数插补会把"没测到"当成真实低值。
  另有 7 个样本的化合物检出率处于最低 2.5%，整行信号可疑。
- **候选方案**：
  A. 维持原状，只做中位数插补；
  B. 哨兵值先置缺失再插补 + 样本检出率作为技术协变量 + 低检出样本降权；
  C. 删除全部低检出样本。
- **我们选了**：**B**（C 会损失 7 个样本，n=250 经不起）
- **理由**：哨兵值是仪器"低于检出限"的编码，不是浓度；样本检出率反映前处理/进样质量，
  与风格无关却会影响所有化合物，必须显式建模而不是让它污染主成分。
  降权而不是删除，保留信息但降低其杠杆。
- **谁拍的板**：参赛队员（审计意见由队员提出并要求全流程统一）
- **AI 起了什么作用**：核实哨兵值与受影响样本、实现屏蔽/协变量/降权，
  并统一接入 Q1、Q2、Q3、稳健性与复合架构；未改变采样与标签。
- **结果**：Q2 的香气 Top-3 不再被铁、蛋白、CO₂ 等非挥发项占据；
  Q3 的化学潜空间在剔除检出率方向后再做 PCA（检出率平均解释 9.7%、最高 36.7% 的特征方差）。
  详细数量见 `results/q2/sample_qc.csv` 与 `docs/数据口径_v1.md`。

    四缺陷约束按设计只改 4 列，硫化物整体不受控，这是完整性缺口；
  - 醋酸新增 3/11 超过 0.145 g/L，但该阈值是感官检测阈值、不适合 Tripel（见下条）。
- **风格依赖阈值（22 风格）**：4VG/乳酸/醋酸/铁 Kruskal p 分别 2.4e-10 / 8.2e-20 /
  1.2e-12 / 4.9e-13。数据支持“一刀切阈值不适合这些化合物”，但**不支持**
  “Tripel 是 POF+ 高 4VG 风格”：Tripel 23/28 在检出限、0/28 超 0.2 mg/L；
  高 4VG 出现在 Wheat（42% 超阈值）、Blond（23%）、Saison（20%）。
  风格内 4VG 与感官 `X4vg` 的相关在 Tripel ρ=0.510（p=0.006），由少数可检出样本驱动。
- **口径边界（必须如实写）**：当前 Q3 `loose` 的定义是“不加重”
  （上界 `max(源值, 阈值)`），**不是**“允许向目标风格正常生理区间靠拢”。
  若论文要后者，应实现**风格条件上界**（如目标风格 P90），属于方法改动，
  本次未做，也未改变主模型。
- **对论文的要求**：Q3 限制里增加两条——①四缺陷约束不等于全异味受控（点名 H2S/MeSH）；
  ②阈值是感官检测阈值而非风格合规上限，需区分绝对缺陷与风格依赖特征。
- **谁拍的板**：参赛队员，2026-10-24 指示执行本项核验；**未改变 Q1/Q2/Q3 主模型与口径**。
- **AI 起了什么作用**：实现重建与检验、跑数、起草文档；判定与论文取舍由队员决定。

### 2026-10-24 · Q1 感官潜状态由无监督 PCA8 改为有监督 PLS8

- **背景**：8 维潜状态此前用 PCA（无监督）。消融显示有监督 PLS8 更贴合预测目标。
- **我们选了**：主流程与复合模型改用 `PLSRegression(n_components=8)`；
  保留 PCA8/FA8/PLS12/CCA 对比表供论文展示。
- **理由**：随机 CV 平均 R² **+0.0117**、分组 CV **+0.0131**；确定性算法，
  不引入额外随机性。原论文中 PLSR 直接预测失败，不等于 PLS 不能作为潜状态层。
- **对论文的要求**：写清“PLS 作为潜状态层 + ET 融合”，不要写成 PLSR 直接回归；
  同时报告 PCA8 等对照，避免只报赢家。
- **谁拍的板**：参赛队员，2026-10-24。

### 2026-10-24 · 更正：Q1 潜状态回退 PCA8（推翻同日 PLS8 采纳）

- **背景**：复跑主流程时发现，`upgrade` 探针的 PCA8 基线用了**更窄的 RidgeCV alpha 网格**
  （PCA8 = 0.2201 / 0.1682），而主流程旧实现是 `logspace(-1,3,9)`。两者不是同一基线，
  因此“PLS8 提升 +0.0117 / +0.0131”不成立。
- **同口径复算**（同一预处理、同一折、同一种子）：
  PCA8+RidgeCV 随机 **0.2411** / 分组 **0.1949**；
  PLS8 随机 **0.2321** / 分组 **0.1813**。PLS8 反而低约 0.009 / 0.014。
- **我们选了**：回退 PCA8+RidgeCV 为主模型；PLS8 保留为 `latent_sens_pls` 对照，
  不删除、不隐藏；论文与报告如实写“PLS8 未超过 PCA8”。
- **理由**：队内规则是“本地 CV 没提升就不换”。采纳更差模型会直接损害主结果。
- **对既有材料的影响**：`results/supplementary/upgrade/REPORT.md` 的 §1.4 结论
  应标注“探针基线口径与主流程不一致，提升不可用于主流程决策”；Q1 主表与复合模型
  以本次同口径复算为准。
- **谁拍的板**：参赛队员，2026-10-24 在看到同口径数字后选择“回退 PCA8（推荐）”。
- **AI 起了什么作用**：发现基线不一致、复算并给出证据、执行回退；决定由队员做。

### 2026-10-24 · Q2 修正中心化口径与正负号混排（两处实现 Bug）

- **背景**：逐行核查发现主表把 50 维全部送进风格中心化矩阵，而文档只对
  39 个香气维度做风格内中心化；同时 Lasso 只按 |coef| 选，负向掩蔽物会进 Top-3。
- **我们选了**：
  1. 香气维度用风格内中心化矩阵；11 个口味/口感维度用未中心化的全样本矩阵，
     使 `coef` 与 `corr` 同口径；
  2. 主表只收正向激动剂（`Lasso(positive=True)`，且 coef>0、Spearman>0）；
     负向掩蔽物另跑有符号 Lasso，输出 `negative_maskers.csv`。
- **理由**：修复前乳酸（原始 ρ=0.448）跌到第 52、乙醇（ρ=0.817）跌到第 64；
  苦味 car-3-en-2-one、酸味 GFS 糖等负系数化合物被误列为 Top-1。修复后
  乳酸回到第 2、苦味首位为苦味质、酸味首位为乳酸、酒体首位为甘油；
  乙醇回到第 5（入选频率 0.953，与第 3 名 0.980 接近）。
- **诚实边界**：正向约束会让少数低信噪比维度只剩 1–2 个稳定正候选
  （如 `A_malt_bread` 仅 furfural 稳定），这些维度标 `low_stability=True`，
  补位不伪造显著性；50 维中 24 维稳定率 <0.6，论文须如实标注。
- **对论文的要求**：方法节写明混合中心化与正负号规则；负向表用于
  “跨模态感官掩蔽效应”讨论，不作为关键驱动化合物。
- **谁拍的板**：参赛队员，2026-10-24 指示修复并重跑。
- **AI 起了什么作用**：定位 Bug、实现修复、重跑与逐项核对；口径由队员拍板。

### 2026-10-24 · Q2 图传播算子保留一阶邻域平滑

### 2026-10-24 · Q3 双轨呈现：`ot_proj` 主档 + Joint QP 安全档

- **背景**：`ot_proj` 的位移更高，但存在 H2S/MeSH 旁路上升与部分感官读出恶化；
  Joint QP 用约束换取全通路不恶化。两者是不同目标，不能混写。
- **我们选了**：主流程保持 `ot_proj`；论文核心对比并列 Joint QP
  「Safety-First Regime」，明确写成 Pareto 取舍。
- **理由**：Joint QP 在 924 对上实现被约束的 5 项感官 0/924 恶化、
  8 项化学 0 新增超标；代价是位移 0.894→0.821、全风格对 0.849→0.775，
  修正代价中位 0.091→0.165。**不是**“同时拿到高位移与零恶化”。
- **诚实边界**：924 对中 H2S 123 次、DES 381 次仍在阈值内上升；
  仅 11 个 Pils→Tripel 样本上 H2S/MeSH/DES 为零上升。两档样本范围必须分别标注。
- **对论文的要求**：主表与补充报告都写双轨；不得把 0.894 与零恶化放进同一句。

### 2026-10-24 · Q1 置换重要性：作为 C3/C4 的模型侧证据，不作因果解释

- **背景**：C3 检查点要 `results/q1/importance.csv` 与模块重要性图；C4 要求
  “与官方 MDI/SHAP 对照”。此前只有 Q2 的 Lasso 选择频率，没有主模型侧的重要性。
- **我们选了**：在主模型 `avg` 上做置换重要性（按风格 5 折、3 种子、每列 3 次置换），
  聚合到化合物与 Q2 共表达模块两级；再逐感官与 Q2 的 Lasso 频率做 Spearman 对照。
  不额外引入 SHAP，理由是多输出 50 维下置换更直接，且能同时覆盖 ET 与潜状态两路。
- **结果**：Top-5 为 Caloric value、Color、Lactic acid、Ethyl octanoate、Ethanol；
  模块级以 Module 0（野菌/乳酸/酚，41 成员）与 Module 3（酵母酯醇，26 成员）最高，

  Spearman **0.110**、Top-10 重合 **0.296**——**方向一致但强度有限**，
  与 X 门“局部稀疏标志物与全局连续主成分互补”的表述一致。
- **诚实边界**：232 个特征中 40 个的 ΔMSE 为负（置换后略好），如实保留不截断；
  共线化合物会分摊重要性；数值不可读成因果效应；折叠间标准差较大。
- **对论文的要求**：写“模型侧重要性 + 稀疏回归频率两路互证但不等价”；
  不得用重要性数值宣称某化合物是感官的因果驱动。
