# 决策记录

> **为什么要有这个文件**：MathorCup 2026 官方《人工智能工具使用规定》要求
> "**核心建模、算法设计、求解与分析由参赛队员独立完成**"，并要求提交
> 《AI工具使用详情说明》。这个文件就是**"决策是队员做的"的证据**，
> 同时**从第一天开始积累《AI工具使用详情说明》的素材**——到 D7 补是补不出来的。
>
> 规则详见 [赛制与学术风险清单.md](赛制与学术风险清单.md) §1。

---

## 怎么写

每次做一个实质决策，加一行。**理由必须是业务/数据理由，不能是"AI 建议的"。**

```markdown
### YYYY-MM-DD HH:MM · 〔决策一句话〕
- **背景**：当前面对什么问题
- **候选方案**：A / B / C（列出来）
- **我们选了**：X
- **理由**：〔业务或数据上的理由〕
- **谁拍的板**：A / B / C
- **AI 起了什么作用**：〔如实写，例："提供了候选方案的性能对比"/"未参与"〕
```
