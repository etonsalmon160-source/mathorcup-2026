## 一、🔴 最重要：MathorCup 官方《人工智能工具使用规定》

**这一条直接影响你们怎么用 AI（包括怎么用我）。**

- **文件**：《MathorCup 数学应用挑战赛人工智能工具使用规定（试行）》
- **发布**：2026 年 8 月（文件落款）；**2026-10-16 在第七届大数据竞赛公告中单独发布**
- **适用**：✅ **适用于 2026 年第七届 MathorCup 大数据竞赛**
- **出处（大数据竞赛公告）**：https://m.saikr.com/contest/notice_detail/49194
- 同一份文件也面向第十六届数学应用挑战赛发布：https://www.saikr.com/c/nd/39401
- 本地存档：`data/raw/MathorCup数学应用挑战赛人工智能工具使用规定（试行）.pdf`

### 1.1 规定原文要点

| 项 | 内容 |
|---|---|
| **允许用 AI 吗** | 允许作为辅助，**但"核心建模、算法设计、求解与分析由参赛队员独立完成"** |
| **覆盖范围** | 大型语言模型（LLM）、生成式 AI、代码辅助工具、智能数学软件、翻译/补全工具 |
| **必须声明** | ✅ **用了 AI → 在参考文献之后说明**；**没用 AI → 也要写"本参赛队未使用任何AI工具"** |
| **正文标注** | AI 生成的内容**必须在正文中标注** |
| **参考文献著录** | 把 AI 工具按 `[编号] 工具名称，版本，机构，日期` 列入参考文献 |
| **额外材料** | 🔴 **使用 AI 的队伍必须额外提交一份 PDF《AI工具使用详情说明》**，含：工具名称/版本、用途与使用阶段、**关键交互记录**、**哪些采纳、哪些人工修改** |
| **代码** | **AI 辅助编程必须在代码注释中注明** |
| **图表** | AI 生成的结果/图表**必须标注** |
| **罚则** | 🔴 不合规者**"视为违反竞赛规则，取消其评奖资格"** |

### 1.2 ✅ 适用性已确认（2026-10-23 核实）

**结论：适用。**

第七届大数据竞赛官网在 **2026-10-16** 单独发布了一条公告：
《【人工智能工具使用规定】2026 年第七届 MathorCup 数学应用挑战赛——大数据竞赛》，
正文与本地存档的 PDF 完全一致。之前"只写第十六届、可能不适用"的疑问**可以关闭**。

> 怀疑的来源合理：本地 PDF 的落款只写"MathorCup 数学应用挑战赛组委会 2026 年 8 月"，
> 正文通篇没出现"大数据竞赛"四个字。是官网把这份文件挂到了大数据竞赛的通知列表下，
> 才确认它对本赛事生效。

**推论**：不遵守的代价是取消评奖资格，所以下面 §1.3 的合规要求**全部按硬约束执行**。

### 1.3 🔴 这条对你们队意味着什么（**必须正视**）

我们到目前为止的分工是：**代码、调研、文档大量由我（Claude）产出**。
既然这份规定适用，那么：

1. **必须写 AI 声明** —— 而且"没使用 AI"这种写法对你们是**假的**，不能那么写
2. **必须额外交一份《AI工具使用详情说明》PDF** —— 这个文件现在还不存在，要现做
3. **AI 辅助写的代码要在注释里注明** —— 现有代码需要补标注
4. **"核心建模、算法设计、求解与分析由队员独立完成"** —— 🔴 **这条最要命**

**关于第 4 条的实话**：
模型选型、融合方案、门控设计、参数配置这些"**建模与算法设计**"层面的决策，
目前**大部分是我提出的**。这在规则下是**高风险**的。

**建议的合规做法**（请你们三人讨论后决定）：
- **决策由你们做，我退回到"执行 + 检查"的位置**：
  我提供候选方案与证据，**最终选哪个、为什么选，由你们判断并写进论文**；
- 论文的**分析、结论、业务解释**由你们写，**不要让我代笔**；
- 我写的代码，**由 CS 哥逐行读懂并确认**，而不是直接交；
- **保留你们的判断痕迹**（讨论记录、决策理由），必要时可作为"独立完成"的证据；
- 如实准备《AI工具使用详情说明》。

> **这不是形式主义。** 我实际做的就是"把活干了"，规则要求的是"人做核心、AI 辅助"。
> 两者有实质差别。**用 AI 不丢人，不声明才丢人。**
>
> **行动项（已关闭）**：2026-10-23 核实——该规定由大数据竞赛官网以独立公告发布，**确定适用**，
> 无需再问组委会。剩余要做的是**执行**：声明、正文标注、代码注释、图表标注、详情说明 PDF。

### 🔴 A 类：一票否决

| # | 坑 | 对策 |
|---|---|---|
| A1 | **不写 AI 声明**（或写了"未使用 AI"但其实用了） | 如实声明；准备《AI工具使用详情说明》PDF |

| A4 | **论文过度雷同 / 抄袭** | 自查；模板只借格式不借内容 |
| A5 | **引用不标来源** | 全部进 `refs.bib` 并标注；无 CSDN/知乎/百科/AI 内容 |
| A6 | **题号与内容不符** | 报名系统里选的题号必须与论文一致（2026 版提交规范原文：不符即取消评奖资格） |

| A8 | **AI 辅助代码未在注释注明 / AI 生成图表未标注** | 逐处补标 |

| # | 坑 | 对策 |
|---|---|---|
