## 4. 判据作废规则

若某判据在真实数据规模上**失效**（分母为空、恒为常数、或结构性不可达）：

- 登记为 **"该判据无效"**，由其余判据承担；
- **不删除、不重设计、不事后调阈值**；
- 写清楚根因，并说明对下游结论的约束。

> 这一条是从 LUAD 项目直接搬过来的教训：当时有多条护栏在真实规模上恒为空转，
> 如实登记反而成了可信度的来源；事后偷偷改口径则会让整篇论文失信。
