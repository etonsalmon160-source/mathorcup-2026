## 0. 全文一句话主线

> 我们把一款啤酒看成一条**两层状态链**：可观测的 231 维化学谱 → 14 维发酵潜状态 →
> 8 维感官潜状态 → 50 个感官评分。问题一学这条链的正向读出，问题二找出潜状态的
> 化学骨架，问题三在同一个状态空间里按风格做条件生成与**受约束的跨风格迁移**。
> 三问共用一套潜状态、一套口径、一套验证，不是三个各写各的模型。

这句话服务四条评分轴：

| 评分轴 | 落点 |
|---|---|
| 论文质量 | 三问逐问作答；每问都有"模型建立—求解—验证"闭环 |
| 代码完整正确高效 | F 冻结 + D0–D6 数据门 + 全流程门控 + `make run-all` 一键复现 |
| 测试集指标 | 50 维平均指标 + 逐维热图 + 多种子稳定性（无官方测试集，只报内部 CV） |
| **创新性 + 跨学科** | 化合物功能模块（生信，问题 2）× 风格作为市场分层（经济，问题 3）× 状态空间/最优传输/约束优化（数学）+ 严格的稳定性与约束验证（CS） |

**两层潜维数都是实测的，不是拍的**：

| 层 | 方法 | 维数 | 解释方差 | 产物 |
|---|---|---:|---:|---|
| 化学潜状态 | 231 化合物做平行分析（100 次置换） | **14** | 62.2% | `results/q3_probe/report.json` |
| 感官潜状态 | 50 个感官维度做平行分析 | **8** | 64.4% | 本轮复核（2026-10-23） |

> 这一条把三问真正串起来：问题一输出 8 维感官状态再解码到 50 维；问题二解释 14 维
> 化学状态由哪些化合物模块构成；问题三在 14 维化学状态空间里生成与迁移。
> **同一个数学对象，三问各用一次**——这是全文最主要的创新叙事。

## 0.5 整体分析流程（从 raw 到三问交付）

> 这是"具体怎么跑"的唯一版本。每一步的产物都落盘、都能被 `make gate` 检查；
> 详细的门控判据见 [门控系统.md](门控系统.md) §2。

```
S0 数据底座
  raw 冻结(F) → 补充数据预注册+冻结(S) → 数据门 D0–D6(D) → 六层 QC(Q)
  产物：MANIFEST、data_contract、results/data_gate/report.json、results/qc/report.json
      │
      ▼
S1 表示层（三问共用，只做一次）
  正态分数变换 + 检出限哨兵识别(CDR) + 5 个派生列剔除
  → 化学潜状态 Z_c（14 维，SVD）→ 感官潜状态 Z_s（8 维）
  → OAV 特征（43 个有阈值化合物）→ 5 大来源模块得分（GSVA/模块均值）
  产物：results/features/*.parquet、docs/data_contract/
      │
      ├──────────────► S2 问题一：化学 → 感官
      │   8 维感官状态为中间层；输入 = 化学潜状态 + OAV + 模块得分
      │   模型：逐目标 Ridge/LightGBM 基线 → 多输出/软门控融合（只留赢过单模型的）
      │   验证：GroupKFold by 风格，3 种子；主指标 = 50 维平均 RMSE（预注册写死）
      │   校准：1D 保序最优传输把连续输出映射到 0–6 分级
      │   产物：results/q1/predictions.csv、metrics.json、calibration.json
      │
      ├──────────────► S3 问题二：网络与 Top-3
      │   图：2.csv（Spearman）为底 + 控制 CDR 的偏相关 + WGCNA bicor/TOM
      │   模块：Louvain/Leiden → 与 8.xlsx 的 Hops/Yeast/Malt/Wild flora 对照
      │   Top-3：三路证据（模型侧 SHAP、相关侧偏 Spearman、网络侧模块中心性+OAV）
      │   稳定性：Bootstrap 入选率 + 分半 Jaccard；低于 0.6 如实标注
      │   产物：results/q2/graph_edges.csv、communities.csv、top3.csv、stability.json
      │
      ├──────────────► S4 问题三：风格条件生成 + 跨风格迁移
      │   生成：Z_c | style ~ N(m_style, S_style)，收缩协方差 → 解码回 231 化合物
      │   迁移：Pils/Lager → Tripel 的 Bures/Wasserstein-2 高斯传输
      │   缺陷：在潜空间做 QP 投影，约束原空间缺陷浓度不恶化（松口径）
      │   评价：保真度（风格分类器）、覆盖（MMD/最近邻）、约束满足、感官保真度
      │   产物：results/q3/generated.csv、transfer.csv、report.json
      │
      └──────────────► S5 互证与稳健性（三问必须互相咬合）
          ① Q1 的预测感官 vs Q3 生成谱经 Q1 模型读出的感官：应一致
          ② Q2 的 Top-3 化合物 vs Q3 潜状态载荷：高载荷化合物应落在 Top-3 邻域
          ③ 3 种子 / Bootstrap / 潜维数 k 敏感性 / 缺陷约束松紧的 Pareto
          产物：results/consistency/checks.json、results/robustness/summary.json
      │
      ▼
S6 论文与交付（G6/G7）
  每节数字可追溯 → 引用核验 → AI 声明 → 复现自检 → 三件套打包
```

**三条流程纪律**：

1. **S1 只做一次。** 三问用同一套特征、同一套潜状态；不许问题一用一套插补、
   问题三换另一套。口径漂移由 D6 契约拦。
2. **S5 不是可选项。** 如果 Q3 生成的谱用 Q1 模型读出后不像 Tripel、或 Q2 的
   Top-3 与 Q3 的载荷不重合，说明三个模型各说各话，必须在论文里如实降级。
3. **每一问都先有基线再谈创新。** 问题一先逐目标 Ridge/均值基线；问题二先直接
   相关排序；问题三先按风格求均值。创新模型必须赢过基线才算数。

## 2. 三问各自怎么写（论证链）

### 2.1 问题一：231 → 50 的多输出预测（状态空间潜因子去噪 + 软门控融合 + 1D 最优传输分级）

**这一问的难点不是"用哪个模型"，而是"在 n=250、p=231、13% 检出限截断伪影与 50 个强相关输出下，怎么让特征干净、评估可信、0–6 分级无畸变"。**

论证链（按这个顺序写）：

1. **业务与生信翻译**：把"预测感官评分"翻译成"含左截断检出限（LOD）噪声的代谢组 → 多维感官表型组回归 + 0–6 离散等级映射"。
2. **质控去噪与状态空间潜状态提取（生信 × 经济联合支点）**：
   - **剥离检出限掉线批次（$\text{CDR}_i$）**：针对 13.0% 单元格共用的 `-1.817819` 检出限哨兵值及 6 个重度掉线样本，提取样本检出率 $\text{CDR}_i$ 与二值检出指示矩阵，用 `limma::removeBatchEffect(design = ~ style, covariates = CDR)` 剥离批次偏移；
   - **分机制插补 9 列 `NA`**：`aroma_hops_sum` 用酒花萜烯成员列重构；低值左截断列（双乙酰等）用左尾分位数（QRILC）填补；批次漏测列（`amyl.acetate` 等）保留缺失指示并用 `impute::impute.knn` 共表达近邻插补；
   - **两层状态空间（实测，不是拍脑袋）**：
     - 化学层：231 个化合物做平行分析（100 次置换）保留 **14 维**，解释 62.2% 方差；
     - 感官层：50 个感官维度做平行分析保留 **8 维**；主模型用 **PCA8 + RidgeCV**
       （随机 CV 0.2411、分组 CV 0.1949），PCA8 解释 64.4% 方差。
       2026-10-24 曾拟改用 **8 维有监督 PLS 潜状态（PLS8）**，但同口径复核发现
       `upgrade` 探针的 PCA 基线用了更窄的 alpha 网格（0.2201 / 0.1682），
       与主流程旧实现不是同一基线；同折复算 PLS8 为 **0.2321 / 0.1813**，
       低于 PCA8，故**维持 PCA8 为主模型**，PLS8 作为对照保留在同口径比较表中。
       FA8/PLS12/CCA 的对照表也保留在结果目录。
     观测方程写成 $\mathbf{x}_i = \Lambda_c \mathbf{z}_{c,i} + \boldsymbol{\gamma}\text{CDR}_i + \boldsymbol{\eta}_i$，
     $\mathbf{y}_i = \Lambda_s \mathbf{z}_{s,i} + \boldsymbol{\epsilon}_i$；
     问题一用 14 维化学状态 $\mathbf{z}_c$ 预测 8 维感官状态 $\mathbf{z}_s$，再把 $\mathbf{z}_s$ 解码到 50 维。
     **为什么要两层**：直接 231→50 有 50 个强相关输出，小样本下逐维建模会互相打架；
     压到 8 维感官状态后，每维都有足够样本，解码矩阵 $\Lambda_s$ 还能给出"哪个感官轴由哪些维度组成"。
     叠加 `8.xlsx` 阈值计算的 **气味活性值 $\text{OAV}$ 受体饱和特征**（`grosch1994oav`）
     与 5 大来源模块得分（`hanzelmann2013gsva` 或模块均值，二者择一，预注册写死）。
3. **为什么用树模型 + TabPFN v2 软门控融合**：n=250、表格数据、单调变换不变；引 `grinsztajn2022why` / `erickson2025tabarena` / `hollmann2025tabpfn`。
   - **源论文已经替我们比较过**：Schreurs 2024（数据来源论文）在同样 250 款酒、50 个感官维度上比了 10 个模型，
     面板 R²：Extra Trees / Random Forest / XGBoost **0.22**，Gradient Boosting **0.21**，
     SVR 0.18，ANN 0.14，**PLSR −0.25**，Lasso 0.05，线性回归 −4.13（严重过拟合）。
     → **不要把 PLSR 当直接多输出主模型**：源论文里它在该数据上已经实测失败
     （−0.25）。我们也试过把 PLS 当 8 维**有监督潜状态层**再与 ET 融合，
     但同口径 3 种子 CV 下低于 PCA8（0.2321 / 0.1813 vs 0.2411 / 0.1949），
     因此只作为对照，不作为主模型；论文里不要写“PLS 显著优于 PCA”。
     我们报告的 Q1 主指标应落在 R² ≈ 0.2 量级，不要期待 0.9。
   - 基线：逐目标 Ridge / LightGBM（按目标真实标准差 $\sigma_m$ 归一化损失权重）；
   - 主模型：引入状态空间潜状态 $\hat{\mathbf{z}}_i$ 与通路模块特征的风格感知软门控融合（TabPFN v2 + LightGBM + CatBoost + 多输出 Ridge，严格受 G5 铁律约束：只采用赢过最好单模型的融合）。
   - **TabPFN v2 的限制**：官方实现只支持单输出、不支持缺失标签；只能逐感官跑，或先把 8 维感官状态作为输出再解码。CPU 推理慢，只作异构对照，不作主力。
4. **验证方案（关键）**：按 **啤酒风格分组交叉验证**（GroupKFold by `tasting_category_fine`），避免同一风格的化学共性泄漏到验证折。写清"为什么不能随机切"。
5. **0–6 分级映射（1D Wasserstein 最优传输）**：
   - 主口径在 `4.csv` 标准化连续尺度上评估；
   - 同时采用 **1D Wasserstein 保序最优传输（Monotone Quantile Optimal Transport，引 `peyre2019computational`）** 与极值线性映射，将连续预测映射至 `0–6` 分级评分，汇报多口径敏感性与 $\pm 1$ 等级一致率。
6. **结果呈现与消融**：
   - 50 维性能热图 + 平均指标 ± 3 种子标准差 + 代表性维度散点；
   - **通路模块消融**：逐组砍掉"状态空间潜状态 $\hat{\mathbf{z}}_i$ / OAV 受体特征 / 5 大生化模块"，报主指标变化是否超过种子间标准差（G4）。
   - **置换重要性（2026-10-24 补，`make importance`）**：主模型 `avg` 在按风格 5 折 ×
     3 种子上逐列置换原始输入，报标准化 MSE 增量；化合物级
     `results/q1/importance.csv`、模块级 `results/q1/importance_modules.csv`、
     与 Q2 Lasso 频率的逐维对照 `results/q1/importance_vs_lasso.csv`；图见
     `figures/q1/fig_q1_importance_top.png`、`fig_q1_module_importance.png`、
     `fig_q1_heatmap.png`。模块 0（野菌/乳酸/酚）与模块 3（酵母酯醇）合计约 45%
     的正向重要性；与 Lasso 频率的平均 Spearman **0.110**、Top-10 重合 **0.296**，
     写成“两路方向一致但强度有限”，**不写因果**。
7. **诚实段落**：哪几维预测较难（罕见缺陷维度，样本极少且风格内方差小）；为什么。

**不要写**："准确率 0.9X"——这里是回归，写 RMSE/MAE/R²/Spearman $\rho$ 和具体维度。

### 2.2 问题二：化合物网络与每个感官的 Top-3（去批次 WGCNA + 多证据合成 + 影子价格）

**这一问最容易被写成"跑个相关性排序"，分数点在"洗掉未检出伪相关后 Top-3 是否稳、是否有受体激活与经济学价值解释"。**

论证链：

1. **图的定义与去伪影构图**：
   - 节点 = **226 个独立化合物**（**严格排除 5 个派生汇总列**，见口径 §6）；
   - 针对 `-1.8178` 共享未检出伪相关与 raw/log 量纲分块效应，采用 **`WGCNA::bicor(maxPOutliers = 0.05)`**（抗离群双权中位相关，引 `langfelder2012bicor`）并在控制样本检出率 $\text{CDR}_i$ 的偏相关基础上构建 **拓扑重叠矩阵（TOM，引 `langfelder2008wgcna`）**。
2. **模块识别**：Louvain / Leiden + 层次聚类 → 得到化合物功能模块；与 `8.xlsx` 已知生化来源（`Hops` 萜烯、`Yeast` 酯醇、`Malt` 美拉德杂环、`Wild flora` 有机酸/酚、`Aging` 陈化醛酮）对照验证。
3. **每个感官维度的 Top-3（三路证据合成）**：
   - 模型侧：问题一模型的 TreeSHAP / 置换重要性；
   - 相关侧：`6.csv` 先验与控制 $\text{CDR}_i$ 后的偏 Spearman；
   - 网络与生物物理侧：TOM 模块内中心性（$k_{\text{ME}}$）与气味活性值 $\text{OAV}$ 超阈值率。
   三路证据秩聚合进 Top-3；给出**方向**（正/负）和**效应大小**。
   - **正向与负向严格分表（2026-10-24 修正）**：主表 Top-3 只收正向激动剂
     （`Lasso(positive=True)`，且 coef>0、Spearman>0）；负向拮抗/掩蔽物另跑有符号
     Lasso，输出 `results/q2/negative_maskers.csv`，用于"跨模态感官掩蔽效应"讨论。
     修复前苦味 car-3-en-2-one（coef −0.051）、酸味 GFS 糖（−0.081）等负系数
     化合物会占据 Top-1；修复后苦味首位为苦味质、酸味首位为乳酸、酒体首位为甘油。
   - **中心化口径逐维一致**：39 个香气维度用风格内中心化矩阵；11 个口味/口感维度
     （乳酸/苦味/酒精/酒体/酸度/甜度/金属/乙酸/余味/CO2/总体）用未中心化全样本矩阵，
     保证 `coef` 与 `corr` 同口径。修复前乳酸（原始 ρ=0.448）跌到第 52、乙醇
     （ρ=0.817）跌到第 64；修复后乳酸回到第 2、乙醇回到第 5（入选频率 0.953）。
4. **双重稳定性（引 `meinshausen2010stability`）**：Bootstrap 重采样入选概率 $\hat{\Pi}_j$ + 随机分半后两半 Top-3 的 Jaccard 系数；稳定率低于阈值（0.6）的维度如实标注"不稳定"。
   - **传播算子不敏感性（2026-10-24 实测，`results/supplementary/upgrade/`）**：
     一阶邻域平均（现行 `_smooth`）、图拉普拉斯扩散 $(\mathbf{I}+\gamma\tilde{\mathbf{L}})^{-1}$、
     带重启随机游走三种算子，在 300 次风格分层 bootstrap 上的分半 Jaccard 中位数
     **均 1.000**（50 维，49/50 维 ≥0.5），三者 Top-3 相对主算子的 Jaccard 为
     **0.98–1.00**（拉普拉斯 0.98、RWR 0.99），按 `8.xlsx` 合成来源的家族匹配率
     **同为 49.5%**（52 是 / 53 否）。因此 Top-3 结论对传播算子不敏感，
     保留一阶邻域平均即可；论文把这条作为稳健性证据，不额外增加方法复杂度。
   - 三路证据合并可用 **Robust Rank Aggregation（RRA）** 或 Borda 计数，比简单平均秩更抗单路异常；
     代谢组学里已有"多数投票 + SHAP"的稳定特征选择先例
     （*A Stable Feature Selection Method Based on Majority Voting and SHAP for High-Dimensional
     Metabolomics Data*, 2025；ScienceDirect PII `S0169260725005863`，**DOI 与作者名单待核**）。
   - **不要只用一条证据**：只按相关排序的 Top-3 会被检出限伪相关主导；模型的 SHAP 又会偏向高方差特征。
     两路不一致时，论文里并列报告，不要强行合成一个"唯一答案"。
5. **与官方参照交叉验证 + 经济学 Hedonic 影子价格**：
   - 与 `8.xlsx` 的 `GBM importance MDI / SHAP Values` 对照重合度；
   - 结合 `8.xlsx` 的 `Beer Prices`（7 渠道真实价格），用 **Rosen 特征价格模型（`rosen1974hedonic`）** 测算关键风味模块的边际溢价（影子价格）与缺陷超标引发的非对称折价。
6. **诚实段落**：相关不等于因果；共表达不等于调控；Top-3 是"多源关联与受体激活证据最强"，不是"机制已由湿实验证明"。

### 2.3 问题三：风格条件生成与跨风格迁移（潜状态条件高斯 + 最优传输 + 缺陷约束 QP）

**这一问的分数点在"小样本下生成怎么稳、迁移怎么在拉升目标风味的同时用数学算子锁死缺陷不恶化"。**

论证链：

1. **问题定义与小样本风格的现实**：
   - 内部队列中 `Kriek`（10 款）、`Lambic`（11 款）、`Pils/Lager`（11 款）样本极少。
   - **外部 5,558 款数据不得进入主模型**：它不是官方附件，感官字段是评论词频而非 0–6 评分，
     且与内部 250 款的重叠尚未排除（见 `docs/补充数据预注册.md`，用途 B 条件允许、用途 C 禁止）。
     论文主结果只用内部 250 款；外部表最多作为**敏感性参考**，且需队员签署 + 排除重叠后才能用。
   - 小样本风格用**经验贝叶斯收缩**：风格均值向全局均值收缩，协方差向池化协方差收缩
     （探针取 $\lambda=20$，作为超参数在稳健性门里扫描）。
2. **条件生成模型（按 n=250 的现实）**：
   - 首选：**潜状态 + 风格条件高斯**：$\mathbf{z}_c \mid \text{style} \sim \mathcal{N}(\mathbf{m}_s, \mathbf{S}_s)$，
     再经 SVD 解码回 231 维。小样本稳、可解释、能直接做最优传输。
   - 备选：秩变换条件高斯 Copula（保留非高斯尾部）；条件 VAE 只作为异构对照，
     **不因为它"看起来高级"就选它**。
3. **跨风格迁移（`Pils/Lager → Tripel`）：高斯最优传输 + 缺陷约束**：
   - **传输**：在 14 维化学潜空间做 Wasserstein-2 最优传输（Bures 几何，
     `peyre2019computational`），把每个 Pils/Lager 样本沿最省力的方向搬到 Tripel 分布。
   - **为什么不能直接搬（已实测）**：Tripel 的 DMS 载荷与风格方向余弦 **0.49**，
     直接传输会让 **11/11** 个 Pils 样本 DMS 超阈值（其中 8 个是新增），
     另有 4 个新增双乙酰超标。这不是模型缺陷，是风格本身的化学耦合。
   - **约束**：在潜空间解一个二次规划
     $\min_{\mathbf{z}} \lVert \mathbf{z}-\mathbf{z}_{\text{OT}}\rVert^2$
     s.t. 原空间缺陷浓度满足口径约束、$\mathbf{z}$ 落在观测支撑盒内。
     约束用**松口径**：`OAV_after ≤ max(OAV_before, 1)`（不新增超标、不加重已有超标），
     t2n 迁移后不升高；同时报告**严口径**（全部低于阈值）作为对照。
   - **实测结论（`make q3-probe`）**：松口径 **11/11 可行、新增超标 0**，
     代价是风格位移只保留 **77%**、QP 修正量为传输距离的 **40%**；
     严口径在模型内也 11/11 可行，但**真实 Tripel 只有 0/28 满足**——
     说明"完全无缺陷的 Tripel"是模型外推，论文必须这样标注，不能当真实风格。
   - **双轨定位（2026-10-24 队内定稿，严禁混写）**：
     - **激进档 `ot_proj`（主流程不变）**：点名 4 项化学缺陷 0 新增超标，
       Pils→Tripel 位移 **0.894**、全风格对 **0.849**；但 H2S/MeSH 旁路显著上升，
       5 项感官读出在多数样本恶化（全风格对中 94% 至少一项恶化）。
     - **全通路安全档 Joint QP（Safety-First Regime，纳入论文核心对比）**：
       在 226 维标准化空间联合求解
       $\min_x \lVert x-x_{\text{OT}}\rVert_W^2+\lambda\lVert x-x_{\text{src}}\rVert_W^2$，
       化学通路约束扩到 DMS/4VG/二乙酰/t2n/H2S/MeSH/DES/铁，
       感官读出约束 stale_hops/dms/diacetyl/barnyard/metallic。
       结果：Pils→Tripel 位移 **0.821**、全风格对 **0.775**；
       5 项感官恶化 **0/924**；8 项化学**零新增超标**；
       **11 个 Pils→Tripel 样本上 H2S/MeSH/DES 零上升**；
       全风格对中 H2S 有 123 个、DES 有 381 个在阈值内上移，
       论文不得写成"全风格对零上升"。
     - 两档构成 **Pareto 取舍**：位移 0.894 → 0.821（全风格对 0.849 → 0.775）
       换取全通路零恶化。写作时必须分别标注档位与样本范围（11 样本 vs 924 对）。
   - **可选的一步法升级（C5 有余力再做）**：把"OT 传输 + QP 投影"合成一个
     **约束 Bures 重心**：$\min B((\mu,\Sigma),(\mu_T,\Sigma_T))$ s.t. 缺陷约束。
     14 维下是 SOCP/SDP，`cvxpy + SCS` 毫秒级；理论依据 Hu & Tabak,
     *Constrained Density Estimation via Optimal Transport*, arXiv:2601.06830 (2026)。
     好处是约束在优化中生效，可能减少 40% 的修正代价；**不做也不影响主线**，
     因为现有两步法已经能给出可行的 Pareto 前沿。
4. **生成质量四轴（缺一不可）**：
   - **保真度**：独立风格分类器对生成样本的判别准确率（必须显著高于随机）；
   - **覆盖/多样性**：生成样本与真实同风格样本的最近邻距离、MMD；
   - **约束满足**：新增超标数、加重超标数、t2n 变化；
   - **感官保真度**：生成谱经问题一模型读出的感官画像与真实 Tripel 的距离
     （探针：约束后 1.29 vs 不约束 0.89，**必须如实报告这个代价**）。
   - 经济侧如果做，只用 `8.xlsx` 的内部价格字段做**情景分析**，不引入外部市场先验；
     做不出可靠的成本模型就诚实写"未量化"。不要为了"跨学科"硬套 CVaR。
5. **诚实段落**：生成与迁移受限于观测流形支撑集，外推到极端配方需湿实验发酵验证；约束满足不等于工业发酵一定零成本实现。
